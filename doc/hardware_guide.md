# ハードウェアガイド

## 必要なもの

| 部品 | 要件 |
|---|---|
| 受信側マイコン | Raspberry Pi Pico 2(RP2350)。**RP2040(無印Pico/Pico W)は不可** — HSTXペリフェラルがRP2350固有のため |
| HDMI出力アドオン | RP2350のHSTX出力(GP12-19)をHDMIコネクタへ配線したボード |
| 送信側マイコン | 任意(MicroPython/pico-sdk問わず、SPIマスターとして送信できるもの) |
| HDMIケーブル+モニタ | 640x480@60Hz表示に対応するもの(ほとんどのモニタで問題ない) |

### HDMI出力アドオンについて

特定製品への依存ではなく、「RP2350のHSTX出力をGP12-19の標準ピン配置で
HDMIコネクタへ引き出す」という配線規約に従っていれば動作する。実機検証済み:

- **PICO-HDMI-PLUS**(Micro Fun)
- **Pico-DVI-Sock** 互換配線

いずれも、Pico 2の裏面に直接ハンダ付け/スタッキングする形でGP12-19を
HDMIコネクタのTMDS信号線へ接続する設計になっている。異なる製品でも
GP12-19のピンアサインが同じであれば動作するはずだが、未検証。

## GPIO配線

### SPI0スレーブ(送信側からの受信)

| 受信側Pico 2 | 機能 | 送信側 |
|---|---|---|
| GP0 | SPI0 RX | 送信側のMOSI |
| GP1 | SPI0 CSn | 送信側の専用CSピン(新設推奨。例: GP28) |
| GP2 | SPI0 SCK | 送信側のSCK |
| GP3 | (未使用) | 受信専用リンクのため配線不要 |
| GND | 共通GND | 送信側のGND |

送信側のSPIバスが他の用途(LCD/SDカード等)と共有されている場合、そちらとは
別の専用CSピンを新設することを推奨する(既存の用途と衝突しないようにする
ため)。実装例のプロジェクトでは、既存のSPI1(GP10=SCK, GP11=MOSI)を共有
しつつ、新設したGP28を専用CSとして使っている。

### HSTX出力(HDMIアドオンへ)

| 受信側Pico 2 | 信号 |
|---|---|
| GP12 | D0+ |
| GP13 | D0- |
| GP14 | CK+ (クロック) |
| GP15 | CK- |
| GP16 | D2+ |
| GP17 | D2- |
| GP18 | D1+ |
| GP19 | D1- |

これはHDMIアドオンボード側の標準配線と一致している前提。ボードをPico 2に
直接スタッキングする製品であれば配線作業は不要。

## 実機で確認済みの注意点

- **SPIモード3必須**: RP2350のPL022 SPIスレーブ実装は、モード0
  (CPOL=0/CPHA=0)だと数byte受信後に同期が崩れる既知の制約がある
  (Raspberry Pi公式フォーラムで複数報告あり)。送信側は使用直前に必ず
  モード3(CPOL=1/CPHA=1)を再設定すること — 他の用途(LCD等)とSPIバスを
  共有している場合は特に重要。
- **CSピンにプルアップ**: 受信側はGP1(CSn)に弱プルアップを掛けている
  (`gpio_pull_up()`)。送信側のGPIO初期化タイミングでCSラインが一時的に
  浮くことによる誤動作を軽減するための保険。
- **信号確認手順**: 配線後、まず`ENABLE_SPI_RX=0`の診断ビルド([build_guide.md](build_guide.md)参照)でHSTX単体の動作を確認してから、
  通常ビルドでSPI受信込みの動作を確認すると原因切り分けがしやすい。
- **目視確認マーカー**: 画面左上16x16pixelに、パケット受信完了ごとに赤/緑が
  交互に切り替わるマーカーが表示される。これが変化しなければSPI受信自体が
  発生していない(配線・モード不一致等を疑う)。起動直後、何も受信していない
  間は青色。

## 送信側の実装に必要な最小構成

1. 送信側の任意のSPIペリフェラルをマスターとして初期化。
2. 専用CSピンを1本、出力・アイドルhighで初期化。
3. 送信直前に毎回モード3・任意のボーレートへ設定(他用途と共有する場合)。
4. [protocol.md](protocol.md)に従って8byteヘッダー+ペイロードを1回のCS Low
   区間で送る。

具体的なコード例は[../demo_sender/](../demo_sender/)のMicroPythonサンプル、
または実プロジェクトでの実装例
([PB-1000_emu_AG2](../../PB-1000_emu_AG2/src/lcd_controller.c)、
[MSX_emu_pico2](../../MSX_emu_pico2/src/msx/msx_core.c))を参照。
